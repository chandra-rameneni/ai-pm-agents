# ai-pm-agents

My day-to-day agent sidekicks, packaged as [Claude Code](https://claude.com/claude-code) plugins.

| Agent | What it does |
|---|---|
| [**Plan My Day**](plugins/plan-my-day) | Reads Slack, Jira, Confluence, Aha!, Gmail/Outlook and your calendar, then DMs you an Eisenhower-matrix plan with focus blocks that fit around your meetings. |

## Install

```bash
/plugin marketplace add chandra-rameneni/ai-pm-agents
```
```bash
/plugin install plan-my-day@ai-pm-agents
```

Then try it on demo data with `plan my day demo`, or for real with `plan my day`.
